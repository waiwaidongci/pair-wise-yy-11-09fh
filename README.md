# 种质库跨库调拨复核台

种质资源跨库调拨的前端复核系统，用于登记检测数据、执行复核规则、安排复检与生成调拨单。

## 业务规则

- 登记字段：批次编号、来源库位、封条编号、目标库位、发芽率、含水率、活力检测日期、申请人。
- 复核闸门（命中任一即只能转入复检）：
  - 含水率高于 13%；
  - 活力检测距今超过 90 天；
  - 目标库位已被其他批次占用。
- 同一封条编号重复申请：不重复占用封条/库位，直接沿用首次申请的结果（批准、复检中或已失效）。
- 复检：记录检测人、复测发芽率、复测含水率、处置结论（合格放行 / 退回干燥 / 重新清选 / 申请报废）与备注，保留多轮复检历史。
- 复检合格且复测含水率 ≤13% 时放行：同时占用封条与目标库位，生成调拨单号（DB-YYYYMMDD-NNN）。
- 同批次出现新检测（新封条登记）时，旧批准立即失效，释放其封条与库位，原记录保留备查。
- 库位占用、批次、历史记录均由同一份状态派生，登记与放行时实时重新校验；数据持久化到 localStorage，刷新后保持一致。

## 技术栈

React 19 + Vite + TypeScript（无后端，localStorage 持久化）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62010

页面提供「重置示例数据」按钮，可恢复初始演示记录。
